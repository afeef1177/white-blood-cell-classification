# Comparative Deep Learning for White Blood Cell Classification

A reproducible research starter repository for comparing CNN-based and transfer-learning approaches to classify five types of white blood cells from microscopic images.

## Research objective
Compare a custom CNN baseline with transfer-learning architectures (ResNet18 and EfficientNet-B0) for five-class WBC image classification.

## Classes
Basophil, Eosinophil, Lymphocyte, Monocyte, Neutrophil.

## Dataset
Dataset source: [White Blood Cells Dataset — Kaggle](https://www.kaggle.com/datasets/masoudnickparvar/white-blood-cells-dataset).

Check the dataset's current licence and terms before use. The dataset is not included in this repository.

## Dataset folder structure
Arrange images as follows (class folder names must match across splits):

```
data/
  train/
    Basophil/
    Eosinophil/
    Lymphocyte/
    Monocyte/
    Neutrophil/
  val/
    Basophil/
    Eosinophil/
    Lymphocyte/
    Monocyte/
    Neutrophil/
  test/
    Basophil/
    Eosinophil/
    Lymphocyte/
    Monocyte/
    Neutrophil/
```

Use patient- or slide-level separation when identifiers are available to reduce data leakage.

## Setup
Python 3.10+ recommended.

```bash
python -m venv .venv
# Windows: .venv\Scripts\activate
# macOS/Linux: source .venv/bin/activate
pip install -r requirements.txt
```

## Train
```bash
python train.py --data-dir data --model resnet18 --epochs 15 --batch-size 32
```

For EfficientNet-B0:
```bash
python train.py --data-dir data --model efficientnet_b0 --epochs 15 --batch-size 32
```

## Evaluate
```bash
python evaluate.py --data-dir data --checkpoint outputs/best_model.pth
```

## Predict one image
```bash
python predict.py --image path/to/image.jpg --checkpoint outputs/best_model.pth
```

## Outputs
- `outputs/best_model.pth`: checkpoint selected by validation macro-F1
- `outputs/training_history.json`: epoch-level training and validation metrics
- `outputs/confusion_matrix.png`: test-set confusion matrix

## Research protocol
1. Document dataset source, licence, class counts, and split strategy.
2. Train a custom CNN baseline and transfer-learning models under comparable conditions.
3. Select models using validation macro-F1; reserve the test set for final evaluation.
4. Report accuracy, macro precision, macro recall, macro-F1, per-class metrics, and confusion matrix.
5. Record software versions, random seed, hardware, hyperparameters, and limitations.

**Research integrity:** This repository is starter implementation code. No trained results are claimed here. Add only metrics generated by your own experiments. This academic prototype is not a clinical diagnostic tool.
